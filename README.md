
# 🚲 Rueda Libre

**Alquila, explora y descubre Medellín sobre ruedas.**

## 📌 Descripción del proyecto

Rueda Libre es un sitio web desarrollado para promocionar un servicio de alquiler de bicicletas en Medellín. Su objetivo es facilitar a los usuarios el descubrimiento de diferentes tipos de bicicletas, consultar tarifas, conocer rutas y acceder a opciones de alquiler.

El diseño busca ofrecer una experiencia visual atractiva, sencilla y fácil de navegar, utilizando una identidad gráfica inspirada en el estilo retro y neo-brutalista.

## 🚀 Recomendación de framework — MiniReto 8

Para este proyecto considero que **Bootstrap** es una buena alternativa para desarrollar y mantener el sitio web.

Aunque CSS personalizado ofrece mucha libertad y Tailwind CSS permite crear diseños muy específicos, Bootstrap facilita el trabajo gracias a sus componentes prediseñados y su sistema de cuadrículas responsive.

Entre sus principales ventajas están:

- Componentes listos para utilizar, como navbar, cards, botones y formularios.
- Sistema de cuadrículas que facilita la adaptación a diferentes pantallas.
- Desarrollo más rápido de interfaces.
- Menor necesidad de escribir estilos desde cero.

Para un sitio de alquiler de bicicletas como Rueda Libre, Bootstrap permite concentrarse más en el contenido y las funcionalidades, sin perder demasiado tiempo construyendo cada componente visual.

# 🌙 Rueda Nocturna

**Descubre Medellín sobre ruedas bajo las estrellas.**

## 📌 Descripción del proyecto

Rueda Nocturna es una landing page diseñada para promocionar experiencias de recorridos nocturnos en bicicleta por Medellín. El sitio permite conocer las rutas disponibles, consultar los planes, descubrir los beneficios del servicio e inscribirse en una experiencia.

El proyecto utiliza una identidad visual retro con estilo neo-brutalista, colores contrastantes, bordes gruesos y sombras marcadas.

-----Justificacion formularios-----

1. Correo electrónico (input type="email): Elegí este tipo porque permite validar que el usuario ingrese 
una dirección de correo con un formato
válido antes de enviar el formulario.

2. Plan de alquiler (input type="radio"): Utilicé botones de opción porque el cliente solo puede 
seleccionar un plan entre las tres alternativas disponibles.

3. Aceptación de políticas (input type="checkbox"): Elegí una casilla de verificación porque permite que el usuario 
confirme explícitamente que acepta las políticas de alquiler. 
Además, con required se obliga a marcarla antes de enviar el formulario.
